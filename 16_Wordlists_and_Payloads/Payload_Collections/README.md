# Payload Collections

Ready-made payload and bypass collections covering many vulnerability classes at once.

It's a collection of multiple types of lists used during security assessments, collected in one place. List types include usernames, passwords, URLs, sensitive data patterns, fuzzing payloads, web shells, and many more. `type:wordlist` `fuzzing` `passwords` `usernames`
