# Practice Labs

Vulnerable machines, platforms, and labs for hands-on practice.

## Resources

<!-- Format: - [Name](https://url) — what it does and why it matters. Tags: `type:tool|course|docs|wordlist|lab|article|video` `platform or tech` -->
- [Damn-Vulnerable-Drone](https://github.com/nicholasaleks/Damn-Vulnerable-Drone) — Damn Vulnerable Drone is an intentionally vulnerable drone hacking simulator based on the popular ArduPilot/MAVLink architecture, providing a realistic environment for hands-on drone hacking. `type:lab` `drone` `mavlink` `ardupilot`
- [GRFICSv3](https://github.com/Fortiphyd/GRFICSv3) — GRFICSv3 is a FREE and open source OT security lab with realistic networking and a 3D process simulation for training and learning ICS security. `type:lab` `ot` `ics` `scada` `plc` `hmi`
- [ICSsVirtualForCiberSec](https://github.com/sfl0r3nz05/ICSsVirtualForCiberSec) — ICSs virtualized lab for cybersecurity testing. `type:lab` `ics` `scada` `modbus` `plc`
- [labshock](https://github.com/zakharb/labshock) — OT Security Lab for ICS networks. `type:lab` `ics` `scada` `modbus` `ot` `plc`
- [OT-NWbasedOnGNS3](https://github.com/sfl0r3nz05/OT-NWbasedOnGNS3) — Project created to practice SDN-based Attack & Defence on Modbus/TCP and HTTP protocols in an ICS network. `type:lab` `modbus` `ics`
- [PwnPad](https://github.com/twelvesec/PwnPad) — PwnPad is an affordable, hands-on hardware hacking platform built for practical learning. It features a range of challenges that walk users through key hardware security concepts, from PCB design to side-channel attacks. `type:lab` `firmware` `hardware` `i2c` `jtag` `lot` `pcb` `spi` `swd` `uart`
- [WifiForge](https://github.com/blackhillsinfosec/WifiForge) — WifiForge is a tool developed by Black Hills InfoSec to help train Pentesters on different Wi-Fi attack vectors and Wireless capabilities. `type:lab` `wifi` `wireless`
